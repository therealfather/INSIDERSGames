# Insiders Corporation Website

Static GitHub Pages website. Upload the contents of this `PUBLIC-SITE` folder to the repository root.

`.nojekyll` is included so GitHub Pages serves the site exactly as static HTML, CSS, JavaScript and media files.

## Local test
Run `START_SITE.bat` and open the displayed localhost address.

## Editing
Use the separate `ADMIN-LOCAL-DO-NOT-UPLOAD` folder. The editor updates `assets/data/site-data.js` and media files.

In the editor, only visible games, published articles and visible custom pages are generated as new public pages. Files generated by a previous editor build are removed when they are later hidden or deleted; existing files that the editor did not create are left untouched.

The editor keeps every article and page (including drafts) in `assets/data/site-data.js`. A save/build also writes `assets/data/editor-backup.json`; this is used automatically if the main editor data file cannot be read. Published article HTML files are generated in `news/`, while drafts stay editable in the local editor without becoming public pages.
